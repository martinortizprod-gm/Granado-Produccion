# Granado-Produccion

Sistema modular para la gestión de procesos y análisis de datos en producción de alimentos para bovinos de la empresa Granado Prod. Vet.

## Web (Next.js)

App web en desarrollo. En local:

```bash
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

El esquema inicial de Supabase está en `supabase/schema_inicial.sql`.
